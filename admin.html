Publish from phone

  1. Tap Download updated JSON.
  2. Open your GitHub repository and tap videos.json.
  3. Tap the pencil/Edit button and replace the old text with the downloaded JSON contents.
  4. Commit changes. Wait a few minutes, then refresh the website.
