VIVO THEME STORE — PHONE SETUP
Files: index.html, style.css, app.js, videos.json.

FREE PUBLISHING:
1. Extract this ZIP on Android.
2. On GitHub, create a PUBLIC repository named vivo-theme-store.
3. Upload all FOUR files to the repository root (not the folder).
4. Open repository Settings > Pages.
5. Select Deploy from a branch, branch main, folder /(root), Save.
6. Wait for the website URL to appear in Settings > Pages.

EDITING CONTENT:
Open videos.json in GitHub, tap Edit (pencil), change a video entry, then Commit changes. The website updates after deployment.

For each video entry:
- section: latest / premium / members / live
- title, category, description, date
- url: YouTube video link
- thumbnail: public image URL, or leave blank
- download: public ZIP file URL; leave blank to hide download button.

Update settings.youtube and settings.telegram to your real channel links. Replace all example.com URLs before publishing. Public download links must be accessible to visitors. YouTube members-only videos still require YouTube membership.

This is a static starter; no separate admin dashboard is included. Editing videos.json is the free phone-based content workflow. Never add passwords or secret API keys to public files.
